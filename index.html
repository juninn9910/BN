🔒 안심하세요! 배포하더라도 내 정보는 남들에게 절대 보이지 않습니다.

아래에 입력하는 주소와 API 키는 서버가 아닌 현재 사용 중인 기기의 브라우저(localStorage)에만 저장됩니다. 다른 사람이 이 사이트에 접속하면 각자 자기의 시트와 API를 연결해 쓰게 됩니다.

연결하지 않아도 현재 기기에 자동 저장되며, 연결 시 구글 시트에 영구 기록됩니다.

✨ 1분 만에 내 구글 스프레드시트 연결하기:

  1. 새 구글 스프레드시트를 하나 만들고 상단 메뉴 [확장 프로그램] → [Apps Script]를 클릭합니다.
  2. 기존 코드를 지우고 아래의 [연동 스크립트 복사하기] 버튼을 눌러 붙여넣은 뒤 저장(💾)합니다.
  3. 우측 상단 [배포] → [새 배포] → 유형: 웹 앱 → 액세스 권한: 모든 사용자(Anyone)로 배포 후 나온 URL을 위 칸에 붙여넣으면 끝!
